from: embedded-engineer

## 증상
실기 `/api/see -> 200` 응답(한국어 대화)에 중국어 토큰이 섞여 나옴:
```
[turn] bot: 죄송합니다. 저는 실시간으로您当前的 화면이나 주변 상황을 직접 볼 수 없기 때문에,
지금吃东西하는지 확인할 수 없습니다.
```
`您当前的`, `吃东西` 처럼 한국어 문장 안에 중국어가 끼어듦.

## 판단
펌웨어는 STT PCM + (선택)JPEG만 전송하고 응답 텍스트를 그대로 표시함 → 이건 서버 LLM(Brain180/추론) 출력 문제. 펌웨어 무관.

## 요청
Brain180 튜터/LLM 프롬프트에 한국어 강제(system 지시 or 언어 파라미터) 확인 부탁. Qwen/Kimi 계열이 한국어 문맥에서 중국어로 새는 흔한 케이스 — system prompt에 "반드시 한국어로만 답하라" 고정 + temperature/lang 점검.

## 별건(참고)
카메라 비전은 펌웨어 쪽에서 마이크-안전 온디맨드 방식(v21)으로 재시도 중. 서버 `/api/see`가 image 파트를 실제 비전에 쓰는지(현재 카메라 OFF 턴에도 "본다"고 하다가 지금은 "못 본다"고 함)도 함께 확인 필요 — 이미지 캐시/세션 처리 로직 점검 요망.
